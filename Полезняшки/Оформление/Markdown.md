Это облегченный язык разметки для удобного форматирования текста с помощью простых символов.

# Зачем он нужен

- Создание читаемого текста без сложных HTML-тегов.
- Быстрое оформление документов, заметок и писем.
- Написание инструкций и файлов `README` на GitHub.
- Лёгкое преобразование в HTML, PDF и другие форматы.

# Примеры простого синтаксиса

- **Заголовки:** ставьте решётку `#` перед текстом.
- **Жирный текст:** оборачивайте слова двумя звёздочками `**`.
- **Курсив:** используйте одну звёздочку `*` или нижнее подчёркивание `_`.
- **Списки:** начинайте строчки с дефиса `-` или звёздочки `*`.

## Разные короткие примеры (из разряда "как сделать")

### Выравнивание содержимого отдельных ячеек в таблице
Возможности выравнивания текста в ячейках средствами самого markdown довольно ограничены. Проще использовать html/css возможности.
Для индивидуального выравнивания содержимого конкретной ячейки в CSS Grid используются свойства **`justify-self`** (по горизонтали) и **`align-self`** (по вертикали), которые применяются к самому дочернему элементу (ячейке), а не к контейнеру.

Дополнительно можно использовать общее свойство **`place-self`**, объединяющее оба этих значения.

Основные свойства для отдельной ячейки

- **`justify-self`** — выравнивает элемент внутри ячейки по горизонтальной оси (по ширине).
    - `start` — по левому краю.
    - `end` — по правому краю.
    - `center` — по центру.
    - `stretch` — растягивает на всю ширину ячейки (значение по умолчанию).

- **`align-self`** — выравнивает элемент внутри ячейки по вертикальной оси (по высоте).
    - `start` — по верхнему краю.
    - `end` — по нижнему краю.
    - `center` — по центру.
    - `stretch` — растягивает на всю высоту ячейки (значение по умолчанию).

- **`place-self`** — сокращение. Первым значением пишется `align-self`, вторым — `justify-self` (например: `place-self: center start;`). Если указать одно значение, оно применится по обеим осям.

#### Пример использования
```html
<div class="grid-container">
  <div class="cell normal">Обычная ячейка (растянута)</div>
  <div class="cell custom-1">По центру ячейки</div>
  <div class="cell custom-2">Вверху и справа</div>
</div>
```
```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 200px);
  grid-template-rows: 150px;
}

.cell {
  background: #f0f0f0;
  border: 1px solid #ccc;
}

/* Элемент выравнивается по центру ячейки */
.custom-1 {
  justify-self: center;
  align-self: center;
}

/* Элемент прижимается к верху и правому краю */
.custom-2 {
  justify-self: end;
  align-self: start;
}
```
