Для удаления стоп-слов в NLTK есть встроенный список, а для лемматизации русского языка лучше всего использовать библиотеку `pymorphy3` (современное и поддерживаемое продолжение `pymorphy2`).

## 1. Установка дополнительных библиотек

Перед запуском кода установите `pymorphy3` и скачайте пакет стоп-слов NLTK через терминал:
```bash
pip install pymorphy3
```
## 2. Полный код: токенизация, очистка и лемматизация
```python
import nltk
from nltk.tokenize import RegexpTokenizer
from nltk.corpus import stopwords
import pymorphy3

# 1. Загрузка ресурсов NLTK (выполняется один раз)
nltk.download('stopwords')

# 2. Инициализация инструментов
# Токенизатор: оставляет слова (включая дефисы) и цифры
tokenizer = RegexpTokenizer(r'[а-яА-ЯёЁa-zA-Z0-9-]+')

# Инициализируем морфологический анализатор для русского языка
morph = pymorphy3.MorphAnalyzer()

# Загружаем русские стоп-слова
russian_stopwords = set(stopwords.words('russian'))

# 3. Исходный текст
text = "Мы уехали на диван-кровати в красивый город, но не успели на поезд."

# 4. Токенизация (переводим в нижний регистр для точного совпадения со стоп-словами)
tokens = tokenizer.tokenize(text.lower())

# 5. Удаление стоп-слов
filtered_tokens = [token for token in tokens if token not in russian_stopwords]

# 6. Лемматизация (приведение к начальной форме)
# morph.parse(word)[0].normal_form возвращает нормальную форму слова
lemmatized_tokens = [morph.parse(word)[0].normal_form for word in filtered_tokens]

# Вывод результатов
print("1. Токены:", tokens)
print("2. Без стоп-слов:", filtered_tokens)
print("3. Леммы:", lemmatized_tokens)
```
### Результат работы скрипта:

- **Токены:** `['мы', 'уехали', 'на', 'диван-кровати', 'в', 'красивый', 'город', 'но', 'не', 'успели', 'на', 'поезд']`
- **Без стоп-слов:** `['уехали', 'диван-кровати', 'красивый', 'город', 'успели', 'поезд']` _(удалились союзы и предлоги: мы, на, в, но, не)_
- **Леммы:** `['уехать', 'диван-кровать', 'красивый', 'город', 'успеть', 'поезд']` _(глаголы стали инфинитивами, существительные — в именительном падеже единственного числа)_
## Spacy

Библиотека `spaCy` решает проблему «зоопарка» технологий. Вместо связки из трех разных инструментов (NLTK для токенов + NLTK для стоп-слов + pymorphy для лемм) вы используете всего **один** инструмент, который делает всё сразу «из коробки».

### 1. Установка библиотеки и модели

Для работы понадобятся сама библиотека и языковой пакет для русского языка. Установите их через терминал:
```bash
pip install spacy
python -m spacy download ru_core_news_sm
```
## 2. Пример кода: всё в одном конвейере

В `spaCy` текст обрабатывается за один проход (`nlp(text)`), создавая объект со всеми свойствами:
```python
import spacy

# 1. Загружаем единую русскую модель
nlp = spacy.load("ru_core_news_sm")

# 2. Исходный текст
text = "Мы уехали на диван-кровати в красивый город, но не успели на поезд."

# 3. Полный анализ текста (токенизация, лемматизация и разбор происходят здесь)
doc = nlp(text)

# 4. Фильтруем токены, одновременно забирая их леммы
# token.is_stop — проверяет на стоп-слово
# token.is_punct — проверяет, является ли токен знаком препинания
# token.lemma_ — возвращает начальную форму в нижнем регистре
lemmatized_tokens = [
    token.lemma_ 
    for token in doc 
    if not token.is_stop and not token.is_punct
]

# Вывод результатов
print("Исходные токены и их свойства:")
for token in doc:
    if not token.is_punct:
        print(f"Слово: {token.text:<15} Лемма: {token.lemma_:<15} Стоп-слово: {token.is_stop}")

print("\nИтоговый очищенный список лемм:")
print(lemmatized_tokens)
```
### Результат работы скрипта:
```text
Итоговый очищенный список лемм:
['уехать', 'диван-кровать', 'красивый', 'город', 'успеть', 'поезд']
```
