Разбор предложения на члены (подлежащее, сказуемое и т.д.) в обработке естественного языка (NLP) называется **синтаксическим разбором** или **Dependency Parsing** (разбором зависимостей).

Для таких задач на базе **PyTorch** обычно используют готовые библиотеки с глубоким обучением (например, `transformers` от Hugging Face или `stanza` от Стэнфордского университета), так как писать архитектуру с нуля долго и сложно.

Ниже показан простой пример на Python, как с помощью предобученной модели из библиотеки `transformers` (которая под капотом использует PyTorch) разобрать предложение на слова и определить их синтаксическую роль (зависимости).

Так как синтаксический разбор (подлежащее/сказуемое) требует специфических грамматических деревьев, на практике в экосистеме PyTorch чаще всего применяют библиотеку **Stanza** или **Natasha** (для русского языка), которые умеют строить деревья синтаксических связей.

# Пример синтаксического разбора для русского языка (через Stanza)
```python
import stanza

# Инициализируем пайплайн для русского языка
nlp = stanza.Pipeline('ru', processors='tokenize,pos,depparse')

# Анализируем предложение
sentence_text = "Мальчик читает интересную книгу."
doc = nlp(sentence_text)

# Выводим слова, их части речи и синтаксическую роль
print(f"{'Слово':<12} | {'Часть речи':<10} | {'Роль (Dep)':<12} | {'Главное слово'}")
print("-" * 50)

for word in doc.sentences[0].words:
    # head - индекс главного слова (0 - корень предложения)
    head_word = doc.sentences[0].words[word.head - 1].text if word.head > 0 else "КОРЕНЬ"
    print(f"{word.text:<12} | {word.upos:<10} | {word.deprel:<12} | {head_word}")
```
Расшифровка ролей (`deprel`):
- **nsubj** (nominal subject) — подлежащее (кто? что?).
- **root** — главное сказуемое (корень предложения).
- **obj** / **obl** — дополнение или обстоятельство.
- **amod** / **det** — определение.

# Синтаксический разбор с помощью библиотеки Natasha

Синтаксический разбор текста на русском языке с помощью библиотеки Natasha выполняется через встроенную нейросетевую модель `NewsSyntaxParser`.

## Пример кода для синтаксического анализа
```python
from natasha import Doc, NewsEmbedding, NewsSyntaxParser, Segmenter

# Инициализируем нужные модули
segmenter = Segmenter()
emb = NewsEmbedding()
syntax_parser = NewsSyntaxParser(emb)

# Текст для разбора
text = 'Кот сидит на коврике.'
doc = Doc(text)

# Шаг 1: Сегментация (разбиение на токены и предложения)
doc.segment(segmenter)

# Шаг 2: Синтаксический разбор
doc.parse_syntax(syntax_parser)

# Выводим визуализацию дерева зависимостей для предложений
for sent in doc.sents:
  sent.syntax.print()

# Получаем данные по каждому слову (id родителя и тип связи)
for token in doc.tokens:
  print(f'{token.text} -> родитель ID: {token.head_id}, связь: {token.rel}')
```

### Основные свойства токена
После вызова `doc.parse_syntax()` у каждого объекта `token` в `doc.tokens` появляются поля:
* `id` — уникальный идентификатор слова в предложении (например, `'1_1'`).
* `head_id` — идентификатор родительского слова (главного в этой связи).
* `rel` — тип синтаксической связи (например, `nsubj` — подлежащее, `root` — корень предложения).
