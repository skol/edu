В библиотеке **pyannote.audio** (начиная с версий v3 и в актуальной v4/`community-1`) передача сырого массива `numpy.ndarray` напрямую в pipeline вызывает ошибку `AttributeError: 'numpy.ndarray' object has no attribute 'unfold'`. [1](https://github.com/pyannote/pyannote-audio/issues/1690)

Библиотека под капотом использует `PyTorch`, поэтому для обработки аудио из оперативной памяти данные необходимо передавать в виде **`torch.Tensor`** в определенном формате. [1](https://github.com/pyannote/pyannote-audio/issues/1684), [2](https://vexascribe.com/pyannote-audio), [3](https://huggingface.co/pyannote/speaker-diarization-3.0)

Ниже приведены 2 рабочих способа обработки аудио из массива.

# Способ 1: Преобразование `numpy` массива в `torch.Tensor` (Рекомендуемый)

Передаваемый словарь должен содержать два обязательных ключа:

- `"waveform"` — двумерный тензор типа `torch.Tensor` с размерностями `(каналы, время)`.
- `"sample_rate"` — частота дискретизации (инт). [1](https://github.com/pyannote/pyannote-audio/issues/1690)
```python
import numpy as np
import torch
from pyannote.audio import Pipeline

# 1. Инициализируем pipeline (нужен токен Hugging Face)
pipeline = Pipeline.from_pretrained(
    "pyannote/speaker-diarization-3.1",  # или "pyannote/speaker-diarization-community-1"
    use_auth_token="ВАШ_HF_TOKEN"
)
pipeline.to(torch.device("cuda" if torch.cuda.is_available() else "cpu"))

# 2. Пример вашего numpy массива (аудио длительностью 10 сек, 16кГц, моно)
# Массив должен быть нормализован (значения от -1.0 до 1.0, тип float32)
np_audio = np.random.uniform(-1.0, 1.0, 160000).astype(np.float32)

# 3. Приведение к правильной форме (каналы, время) -> (1, 160000)
if len(np_audio.shape) == 1:
    np_audio = np_audio[np.newaxis, :]  # Добавляем ось каналов

# 4. Конвертируем в PyTorch Tensor
torch_waveform = torch.from_numpy(np_audio)

# 5. Собираем структуру для pyannote
audio_in_memory = {
    "waveform": torch_waveform,
    "sample_rate": 16000
}

# 6. Запускаем диаризацию
diarization = pipeline(audio_in_memory)

# Вывод результатов
for turn, _, speaker in diarization.itertracks(yield_label=True):
    print(f"Старт: {turn.start:.1f}с | Конец: {turn.end:.1f}с | {speaker}")
```
# Способ 2: Через виртуальный файл в памяти (`io.BytesIO`)

Если ваше аудио изначально хранится в бинарном массиве байт (например, прочитано из сети или буфера в формате `.wav`/`.mp3`), вы можете обернуть его в `io.BytesIO`. Для чтения структуры такого файла `pyannote` использует класс `Audio`. [1](https://github.com/pyannote/pyannote-audio/issues/955), [2](https://github.com/pyannote/pyannote-audio/issues/1316)
```python
import io
from pyannote.audio import Audio, Pipeline

# Ваши бинарные данные аудиофайла (bytes)
audio_bytes = b"..." 

# Оборачиваем в поток ввода-вывода в памяти
audio_stream = io.BytesIO(audio_bytes)
audio_stream.seek(0)

# Читаем данные с помощью встроенного модуля Audio
# Это автоматически вернет правильный waveform (Tensor) и sample_rate
waveform, sample_rate = Audio()(audio_stream)

audio_in_memory = {
    "waveform": waveform, 
    "sample_rate": sample_rate
}

# Передаем в пайплайн
diarization = pipeline(audio_in_memory)
```
# Важные нюансы при работе в памяти:

- **Тип данных:** Убедитесь, что массив `numpy` имеет тип `np.float32`. Если аудио прочитано из 16-битного WAV как целые числа, разделите массив на `32768.0` для нормализации. [1](https://github.com/pyannote/pyannote-audio/issues/1690)

- **Размерность:** Обязательно проверяйте размерность матрицы. `pyannote` ожидает ровно **2D-массив** `(channels, samples)`. Если аудио моно и массив одномерный, используйте `np.expand_dims` или `[np.newaxis, :]`. [1](https://github.com/pyannote/pyannote-audio/issues/1690)
