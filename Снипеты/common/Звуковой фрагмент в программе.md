Как воспроизвести звуковой фрагмент в программе:
```python
import os  
  
os.environ['PYGAME_HIDE_SUPPORT_PROMPT'] = '1'  
  
import pygame  
import time  
  
pygame.init()  
pygame.mixer.init()  
  
# 1. Загружаем аудиофайл  
pygame.mixer.music.load("recept.mp3")  
  
START_POS = 80.0  # Позиция старта в секундах (float)  
DURATION = 5.0    # Длительность воспроизведения в секундах (float)  
  
# 2. Воспроизведение с заданной позиции (loops=0 — сыграть 1 раз)  
pygame.mixer.music.play(loops=0, start=START_POS)  
  
# 3. Отсчитываем нужную длительность  
# В реальной игре этот блок заменяется стандартным игровым циклом (while True)  
time.sleep(DURATION)  
  
# 4. Останавливаем воспроизведение по истечении времени  
pygame.mixer.music.stop()  
print("Воспроизведение завершено.")
```
⚠️ **Важно для MP3:** Позиционирование в MP3 не всегда работает со стопроцентной точностью из-за особенностей кодирования. Для идеальной точности используй формат **OGG**.
