Для вывода картинок в терминальных приложениях на фреймворке **Textual** используется специальный сторонний пакет `textual-image`, который поддерживает протоколы графического вывода в терминале (TGP, Sixel) и резервный Unicode-режим.

## Поддерживаемые терминалы

Отображение графики зависит от вашего терминала:
- **Поддерживаются:** Kitty, WezTerm, iTerm2, VS Code, Windows Terminal (v1.22+), Foot, Tmux.
- **Не поддерживаются:** GNOME Terminal, Warp.

```python
from textual.app import App, ComposeResult  
from textual_image.widget import Image  # или актуальный класс из пакета textual-image  
  
class ImageApp(App):  
    def compose(self) -> ComposeResult:  
        # Передаем путь к вашему изображению  
        yield Image("portal.png")  
  
if __name__ == "__main__":  
    app = ImageApp()  
    app.run()
```
