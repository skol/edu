Самый популярный и удобный способ убрать фон локально — это использовать библиотеку **`rembg`** на базе Python. Она работает полностью офлайн и поддерживает различные ИИ-модели (например, _u2net_, _isnet_ или _BiRefNet / RMBG-2.0_). [1](https://github.com/tecnomanu/remove-background-local), [2](https://github.com/danielgatis/rembg), [3](https://docs-python.ru/packages/udaleniya-fona-s-izobrazhenii/), [4](https://github.com/Bria-AI/RMBG-2.0)

# Вариант 1. Через командную строку (Python `rembg`)

1. **Установите Python** (версии 3.8 или выше) и пакет `rembg` через терминал:
```bash
# cpu 
pip install rembg[cli]
# cuda
pip install rembg[gpu]
```
2. **Уберите фон с одного файла**:
```bash
rembg i path/to/input.png path/to/output.png
```
3. **Обработать целую папку с фотографиями**: [1](https://github.com/danielgatis/rembg)
```bash
rembg p path/to/input_folder path/to/output_folder
```

# Вариант 2. С готовым графическим интерфейсом (GUI)

Вы можете запустить удобные программы с визуальным интерфейсом на базе `rembg`:

- **GIMP с плагином Rembg**: установите дополнение gimp-rembg-plugin или [gimp3-rembg-plugin](https://github.com/ismdevteam/gimp3-rembg-plugin), чтобы вырезать фон прямо внутри редактора GIMP.
- **Rembg-GUI / Free Rembg Desktop**: готовые десктопные приложения с функцией Drag-and-Drop (перетаскивания файлов), которые можно найти и скачать на [GitHub - free-rembg-desktop](https://github.com/Remove-Background-ai/free-rembg-desktop). [1](https://github.com/Tech-Archive/gimp-rembg-plugin), [2](https://github.com/ismdevteam/gimp3-rembg-plugin), [3](https://github.com/Remove-Background-ai/free-rembg-desktop), [4](https://github.com/redevil1/rembg-gui)
